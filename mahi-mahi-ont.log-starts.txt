usage: mahi-mahi [-h] [--version] (--bam BAM | --cram CRAM) --ref
                 REFERENCE_GENOME_FASTA --loci BED --sample SAMPLE --sex
                 {XX,XY} -o OUT_DIR [-c CONFIG] [--profile PROFILE]
                 [--set KEY=VALUE] [--repeat-id REPEAT_ID] [--no-clustering]
                 [--debug] [--bypass-haplotag-check] [--overwrite]

mahi-mahi v1.0.0: Short Tandem Repeat analysis from nanopore data. Arguments
*not* in [] are required. See README.md for more detailed help.

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --bam BAM             BAM file
  --cram CRAM           CRAM file
  --ref REFERENCE_GENOME_FASTA
                        Reference genome file (FASTA format)
  --loci BED            BED file with STR loci, or built-in STR loci shortcut
                        (hg19 or hg38)
  --sample SAMPLE       Sample name to use in output VCF file, and as the stem
                        of every output filename
  --sex {XX,XY}         Sex of sample
  -o OUT_DIR, --out-dir OUT_DIR
                        Path to output directory
  -c CONFIG, --config CONFIG
                        Path to mahi-mahi YAML config file. Defaults to the
                        built-in file shipped with mahi-mahi (site-
                        packages/mahi_mahi/data/config.yaml).
  --profile PROFILE     Named config profile to apply after defaults.
  --set KEY=VALUE       Override a config value; repeat for multiple
                        overrides. Examples: --set
                        min_read_support_per_allele=6, --set
                        strand_bias_method=counts_threshold, --set
                        strand_bias_exclude_suspicious_reads=none.
  --repeat-id REPEAT_ID
                        Repeat ID to analyze (omit to analyze all repeats in
                        --loci)
  --no-clustering       Turns off clustering of reads into two alleles based
                        on read alignment length, and instead uses existing
                        haplotypes only
  --debug               Enable debug messages for detailed logging
  --bypass-haplotag-check
                        Accept non-haplotagged input. Caution: will result in
                        merging close-in-length alleles, and may more
                        generally reduce accuracy
  --overwrite           Allow --out-dir to be non-empty, overwriting any
                        existing mahi-mahi output in it

For research use only.
