==========================================================================================

STRhub Verified does NOT host or redistribute full genomes. The BAM file in

derived from publicly available Genome in a Bottle (GIAB) PacBio HiFi data. It
is used only as a smoke-test input for the external verification leg.

How the slice was built (2026-09-29)
------------------------------------
Region BED: `pacbio_slices/codis_pm10kb.bed` (a copy of `ont_slices/codis_pm10kb.bed`:
            the CODIS core and common forensic STR loci, ±10 kb, hg38).

  samtools 1.21 (quay.io/biocontainers/samtools:1.21--h50ea8bc_0), reading the
  upstream file over HTTPS through its index:

  samtools view -b -M -L codis_pm10kb.bed -X \
      -x fi -x fp -x ri -x rp -x ip -x pw -x sn \
      -o raw.bam <upstream .bam URL> <upstream .bai URL>
  samtools sort -o HG002.hifi.codis.bam raw.bam
  samtools index HG002.hifi.codis.bam

The -x options drop the per-base kinetics (fi/fp/ri/rp/ip/pw) and the
signal-to-noise tag (sn), which no STR genotyper reads and which would double
the file. Nothing else is changed: sequences, qualities, alignments, read
groups, haplotags and methylation tags are as distributed.

Result: pacbio_slices/HG002.hifi.codis.bam, 19.4 MB, 2,396 primary alignments
plus 43 supplementary; mean read length 17.3 kb; 26 windows on 18 contigs
(chrX and chrY included: HG002 is male).

Panel
-----
datasets/pacbio-hifi-bam-hg38/loci.bed and regions/ are DERIVED from the
illumina-bam-hg38 panel by harness/build_regions_library.py (the loci whose
window falls inside the slice windows): 20 autosomal CODIS loci. Measured on
this slice on 2026-09-29, every one of them is overlapped by 19 to 73 primary
HiFi reads (TH01 lowest, D8S1179 highest).
