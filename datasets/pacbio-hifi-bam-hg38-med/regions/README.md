# Regions library for `pacbio-hifi-bam-hg38-med`

51 disease-associated STR loci of `illumina-bam-hg38-med` that fall inside the slice windows (`pacbio_slices/medical_pm10kb.bed`), hg38, in every layout STRhub knows. Derived by `harness/build_regions_library.py` from the `illumina-bam-hg38-med` library by coordinates; do not edit by hand.

The files carry no comment line on purpose: GangSTR and HipSTR reject or misread one.
