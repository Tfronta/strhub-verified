# Regions library for `ont-fastq`

20 forensic STR loci of `illumina-bam-hg38` that fall inside the slice windows (`ont_slices/codis_panel_windows.bed`), hg38, in every layout STRhub knows. Derived by `harness/build_regions_library.py` from the `illumina-bam-hg38` library by coordinates; do not edit by hand.

The files carry no comment line on purpose: GangSTR and HipSTR reject or misread one.
