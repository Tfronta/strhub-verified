# Regions library for `illumina-bam-hg38-y`

17 forensic STR loci the reference slice covers (`datasets/illumina-bam-hg38-y/loci.bed`), hg38, written in every layout STRhub knows. Generated by `harness/build_regions_library.py` from `str_candidates.bed`; do not edit by hand.

| file | layout | for |
|---|---|---|
| hipstr.bed | chrom start end period ref_copies name motif | HipSTR `--regions` |
| gangstr.bed | chrom start end period motif | GangSTR `--regions` |
| strsearch.bed | 11 columns with flanking sequences | STRsearch `--ref_bed` |
| bed4.bed | chrom start end name | any BED-reading tool |

The files carry no comment line on purpose: GangSTR and HipSTR reject or misread one.
