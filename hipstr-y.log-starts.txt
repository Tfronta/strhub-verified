Usage: HipSTR --bams <list_of_bams> --fasta <genome.fa> --regions <region_file.bed> --str-vcf <str_gts.vcf.gz> [OPTIONS]

Required parameters:
	--bams          <list_of_bams>        	Comma separated list of BAM/CRAM files. Either --bams or --bam-files must be specified
	--fasta         <genome.fa>           	FASTA file containing all of the relevant sequences for your organism   
	                                      	  When analyzing CRAMs, this FASTA file must match the file used for compression
	--regions       <region_file.bed>     	BED file containing coordinates for each STR region
	--str-vcf       <str_gts.vcf.gz>      	Bgzipped VCF file to which STR genotypes will be written

Optional input parameters:
	--bam-files  <bam_files.txt>          	File containing BAM/CRAM files to analyze, one per line 
	--ref-vcf    <str_ref_panel.vcf.gz>   	Bgzipped input VCF file of a reference panel of STR genotypes. VCF alleles will be
	                                      	 used as candidate variants instead of finding candidates in the BAMs/CRAMs (Default)
	--snp-vcf    <phased_snps.vcf.gz>     	Bgzipped input VCF file containing phased SNP genotypes for the samples
	                                      	 to be genotyped. These SNPs will be used to physically phase STRs 
	--stutter-in <stutter_models.txt>     	Use stutter models in the file to genotype STRs (Default = Learn via EM algorithm)

Optional output parameters:
	--log           <log.txt>             	Output the log information to the provided file (Default = Standard error)
	--viz-out       <aln_viz.gz>          	Output a file of each locus' alignments for visualization with VizAln or VizAlnPdf
	--stutter-out   <stutter_models.txt>  	Output stutter models learned by the EM algorithm to the provided file

Optional read filtering parameters:
	--no-rmdup                            	Don't remove PCR duplicates. By default, they'll be removed
	--use-unpaired                        	Use unpaired reads when genotyping. (Default = False)
	--max-mate-dist <max_bp>              	Remove reads whose mate pair distance is > MAX_BP (Default = 1000)

Optional VCF formatting parameters:
	--max-flank-indel <max_flank_frac>    	Don't output genotypes for a sample if the fraction of reads containing an indel
	                                      	 in the sequence flanking the STR is greater than MAX_FLANK_FRAC (Default = 0.15)
	--output-gls                          	Write genotype likelihoods to the VCF (Default = False)
	--output-pls                          	Write phred-scaled genotype likelihoods to the VCF (Default = False)
	--output-phased-gls                   	Write phased genotype likelihoods to the VCF (Default = False)
	--output-filters                      	Write why individual calls were filtered to the VCF (Default = False)

Optional BAM/CRAM tweaking parameters:
	--bam-samps     <list_of_samples>     	Comma separated list of read groups in same order as BAM/CRAM files. 
	                                      	  Assign each read the read group corresponding to its file. By default, 
	                                      	  each read must have an RG tag and the sample is determined from the SM field
	--bam-libs      <list_of_libraries>   	Comma separated list of libraries in same order as BAM/CRAM files. 
	                                      	  Assign each read the library corresponding to its file. By default, 
	                                      	  each read must have an RG tag and the library is determined from the LB field
	--lib-field                           	Read group field used to assign each read a library. By default,  
	                                      	  the library is determined from the LB field associated with RG

Optional haplotype filtering parameters:
	--max-haps <max_haplotypes>           	Maximum allowable candidate haplotypes for an STR (Default = 1000)
	                                      	 Loci with more candidate haplotypes will not be genotyped
	--max-hap-flanks <max_flanks>         	Maximum allowable non-reference flanking sequences for an STR (Default = 4)
	                                      	 Loci with more candidate flanks will not be genotyped
	--min-flank-freq <min_freq>           	Filter a flank if its fraction of supporting samples < MIN_FREQ (Default = 0.01)

Other optional parameters:
	--help                                	Print this help message and exit
	--version                             	Print HipSTR version and exit
	--quiet                               	Only output terse logging messages (Default = output all messages)
	--silent                              	Don't output any logging messages  (Default = output all messages)
	--def-stutter-model                   	For each locus, use a stutter model with PGEOM=0.9 and UP=DOWN=0.05 for in-frame
	                                      	 artifacts and PGEOM=0.9 and UP=DOWN=0.01 for out-of-frame artifacts
	--chrom              <chrom>          	Only consider STRs on this chromosome
	--haploid-chrs       <list_of_chroms> 	Comma separated list of chromosomes to treat as haploid (Default = all diploid)
	--hap-chr-file       <hap_chroms.txt> 	File containing chromosomes to treat as haploid, one per line
	--min-reads          <num_reads>      	Minimum total reads required to genotype a locus (Default = 100)
	--max-reads          <num_reads>      	Skip a locus if it has more than NUM_READS reads (Default = 1000000)
	--max-str-len        <max_bp>         	Only genotype STRs in the provided BED file with length < MAX_BP (Default = 100)
	--fam <fam_file>                      	FAM file containing pedigree information for samples of interest. Use the pedigree
	                                      	  information to filter SNPs prior to phasing STRs (Default = use all SNPs)
